# e-plantShopping

Starter workspace for the Paradise Nursery React project.

## Before you continue

This is a learning scaffold, not a completed assignment. Implement and understand each TODO yourself, then follow the course rules before submitting anything.

## Run locally

1. Install Node.js.
2. Run `npm install`.
3. Run `npm run dev`.

## Project structure

- `App.jsx`: application shell and page navigation TODOs
- `AboutUs.jsx`: company information TODO
- `ProductList.jsx`: categorized product listing TODOs
- `CartSlice.jsx`: cart reducer TODOs
- `CartItem.jsx`: cart page and quantity controls TODOs
- `App.css`: layout and landing background TODOs
